# JOUR 2 : Visualisation de Donnees Multi-Graphiques

## Description du Projet

Ce projet consiste a analyser le celebre dataset Iris et a creer un tableau de bord interactif avec 4 graphiques differents. Le projet inclut egalement le calcul des statistiques descriptives (moyenne, mediane, ecart-type, quartiles).

---

## Objectifs

- Charger et explorer un dataset CSV
- Calculer les statistiques descriptives
- Creer un dashboard multi-graphiques (subplot 2x2)
- Soigner la mise en forme (titres, legendes, annotations)
- Sauvegarder le resultat en image PNG

---

## Les 4 Graphiques

| Position | Type | Description |
|----------|------|-------------|
| Haut-Gauche | Histogramme | Distribution de la longueur des petales par espece |
| Haut-Droite | Scatter Plot | Relation longueur-largeur des petales avec regression lineaire |
| Bas-Gauche | Heatmap | Matrice de correlation entre les variables |
| Bas-Droite | Courbes | Evolution des mesures pour les 150 echantillons |
